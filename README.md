# Playwright Banking Automation Framework

## Overview

This project is an end-to-end automation testing framework developed for the ParaBank banking application using Playwright, Cucumber BDD, and TypeScript.

The framework follows the Page Object Model (POM) design pattern and includes UI automation, API testing, reporting, GitHub Actions CI, and Jenkins integration.

---

# Technologies Used

* Playwright
* Cucumber BDD
* TypeScript
* Node.js
* Jenkins CI/CD
* GitHub Actions
* Multiple Cucumber HTML Reporter
* API Testing

---
